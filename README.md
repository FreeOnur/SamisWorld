# SamisWorld

Game created by Onur Arslan about a Samurai in a 2D Pixel World.

## Version 2 (aktuell)

Samis World wird neu aufgesetzt. Dieses Repo enthält im Moment die Design-Grundlagen für v2:

- `Art-Style/` – Art Style Guide, Farbpaletten (.gpl) und Referenzbilder
- `Freunde-Bosse/` – Boss-Vorlage für Freunde (spoilerfrei)
- `Story/` – Story-Material

Das Unity-Projekt für v2 kommt später dazu.
